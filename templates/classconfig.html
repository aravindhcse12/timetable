Class Configuration


What is Class Configuration?

Class Configuration is the first step before generating any timetable. Here you define which subjects are taught to each class, who teaches them, how many periods per week they require, and how those periods should be grouped (split). Without completing this setup, the Auto Generate feature on the Timetable page will have nothing to schedule.

Configure Theory Subjects

Theory subjects are regular lecture periods taught by a single faculty member.

Steps:

  1. Select Course (e.g., B.Tech CSE) and Semester to filter the correct class.
  2. Select Department and the Faculty who will teach this subject.
  3. Select the Subject (Theory type).
  4. Set No. of Periods (per week) — the total number of periods this subject needs in a week.
  5. Set Split Periods — how those periods should be spread across the week (see Split Periods section below).
  6. Click Add.

Configure Lab Subjects

Lab subjects require consecutive periods in a dedicated lab room and may involve multiple faculty members.

Steps:

  1. Select Course and Semester.
  2. Select the Lab Subject (Lab type).
  3. Select the Lab Room(s) to be used.
  4. Set No. of Periods (per week) — total lab periods needed per week.
  5. Set Count of Faculty — number of faculty required to supervise the lab simultaneously.
  6. Set Split Periods — lab periods are typically grouped together (e.g., 3 means one 3-period block per week).
  7. Click Add. The system will automatically assign supporting faculty from the same department during timetable generation.

Configure Project

Project sessions are similar to labs — they need consecutive periods and can involve a guide/supervisor.

Steps:

  1. Select Course and Semester.
  2. Select the Project Subject.
  3. Set No. of Periods (per week).
  4. Set Count of Faculty — number of supervisors needed.
  5. Set Split Periods.
  6. Click Add. Faculty will be auto-assigned from the department during generation if not manually specified.

Split Periods — How It Works

The Split Periods field controls how a subject's weekly periods are broken into blocks across different days. Enter comma-separated values where each number is the size of one block. The sum of all split values must equal the total No. of Periods.

  • Example 1 — One period per day: If a subject needs 6 periods/week and you want one period on each of 6 days, set Split Periods to 1,1,1,1,1,1.
  • Example 2 — Two consecutive periods per day: If a subject needs 6 periods/week and you want 2 back-to-back periods on 3 days, set Split Periods to 2,2,2.
  • Example 3 — Lab block: If a lab needs 3 periods/week as a single continuous session, set Split Periods to 3.
  • You can mix block sizes: e.g., 2,1,1 means one 2-period block and two single periods (total = 4 periods/week).
  • Each block is placed on a different day — the scheduler will not put two blocks of the same subject on the same day.

Delete Button

Removes a subject entry from the class configuration. Check the checkbox next to the configuration row you want to remove and click Delete.
Note: If the subject has already been scheduled in the timetable, delete its timetable entries first (on the Class-wise Timetable page) before deleting the configuration here.
